Design a complete high-fidelity UX/UI system for a mobile-first web application called “RBC GO”, an electric bicycle and electric scooter rental platform.

Use the uploaded RBC GO logo as the exact brand reference.
Do NOT redesign, distort, replace, reinterpret, or change the RBC GO logo.

The application is a mobile web app designed primarily for smartphone users.

==================================================
PRODUCT CONCEPT
==================================================

RBC GO is an electric mobility rental platform.

The main user flow is:

1. User opens the RBC GO web app.
2. User signs in using phone number + OTP or another supported login method.
3. User has an RBC GO system wallet / digital card.
4. User must top up money into the wallet before using a vehicle.
5. User can view nearby electric bicycles and electric scooters.
6. User selects a vehicle or scans the QR code attached to the vehicle.
7. The system verifies:
   - Vehicle availability
   - Battery level
   - User wallet balance
   - Vehicle ID
8. User confirms unlocking the vehicle.
9. Vehicle becomes active and the trip starts.
10. During the ride, the user sees:
   - Ride duration
   - Current cost
   - Distance traveled
   - Vehicle battery
   - Remaining range
   - Current location
   - Live route
11. User ends the trip.
12. The system deducts the rental fee from the RBC GO wallet.
13. User receives a trip summary and receipt.
14. User can review previous trips, payments, wallet transactions, and profile settings.

The UX should make this flow extremely easy to understand even for first-time users.

==================================================
VEHICLE DESIGN
==================================================

When showing RBC GO vehicles:

Use realistic modern electric bicycles and electric scooters.

Main vehicle colors:

- Black
- Charcoal
- Neon lime green details

Add subtle RBC GO branding.

Electric bicycle characteristics:

- Compact urban design
- Battery
- Basket when appropriate
- Front and rear lights
- Strong city commuter appearance

Electric scooter:

- Black body
- Green stem/accent
- Integrated light
- Urban rental design

Avoid unrealistic futuristic vehicles.

MAP DESIGN
==================================================

Use a clean dark map.

Vehicle markers:

Green bicycle marker:
Available e-bike.

Green scooter marker:
Available e-scooter.

Gray marker:
Unavailable.

Blue circular marker:
User position.

Show parking zones clearly.

Do not overload map labels.

==================================================
UX PRINCIPLES
==================================================

Prioritize:

1. Scan to ride
2. Wallet balance
3. Vehicle availability
4. Vehicle battery
5. Current trip status
6. End trip
7. Emergency help

Users should understand the main action within 2–3 seconds.

Buttons should be easy to tap with one hand.

Important CTA buttons should have a minimum comfortable mobile touch area.

Use clear confirmation before destructive or financial actions.

Do not hide critical information behind unnecessary menus.

==================================================
OUTPUT REQUIREMENTS
==================================================

Generate a COMPLETE UX/UI mobile application concept, not only one screen.

Create the screens as a consistent design set.

All pages must use exactly the same visual system.

Show each screen separately, not merged into one collage.

Do not combine multiple mobile screens into one phone.

One screen = one individual mobile mockup.

Keep the full phone visible.

Do not crop the smartphone frame.

Use consistent phone size and presentation angle.

Prefer straight front-facing phone mockups.

Use clean light gray or white background outside the device.

Use high fidelity production-quality UI.

All text should be readable.

Use Thai language for application UI.

Use English only where appropriate for:
RBC GO
vehicle IDs
payment providers
technical terms.

Do not invent a different brand.

Do not replace the RBC GO identity.

The final result should feel like a real commercial electric mobility product that could be implemented as a responsive mobile web app.
