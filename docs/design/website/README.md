# RBC GO website — selected reference

The user-selected six-panel black/lime reference is `selected-reference.png`. It supersedes the earlier exploratory redesign.

Implemented routes in English and Thai: home, Fleet (`rides`), How it works, Pricing, About and Help. Local preview: http://127.0.0.1:5185/en.

`implemented-pages.png` shows six sections from the running production build. `comparison-board-pass3.png` pairs each source panel with its implementation. Full QA and validation results are in the repository-root `design-qa.md`.

Assets are generated illustrations/photographs created for this implementation. Material UI icons retain the copied library license under the website public icons directory. Inter and Kanit use their accompanying OFL licenses.

The website presents a planned service. Rates, payment providers, IoT adapters, support contacts and launch policies require real configuration before launch; illustration content does not establish working wallet or vehicle functionality.
